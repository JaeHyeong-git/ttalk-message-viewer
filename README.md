# TTalk 쪽지 뷰어

TTalk 사내 메신저의 쪽지 백업 txt 파일을 카카오톡처럼 대화 상대별로 정리해서 보여주는 브라우저용 뷰어입니다.

## 배경

TTalk의 쪽지 보관 정책이 최근 30일로 변경되면서, 그 이전 쪽지는 자동 삭제됩니다. 주기적으로 txt 파일로 백업할 수는 있지만, 단일 텍스트 파일로 다운로드되어 조회와 검색이 매우 불편합니다. 이 뷰어는 그 백업 파일들을 모아서 한 곳에서 쉽게 조회·검색할 수 있도록 만든 도구입니다.

## 특징

- **설치 불필요**: HTML 파일 하나로 동작하며, 브라우저에서 더블클릭만 하면 실행됩니다. `.exe`가 아니므로 사내 보안 정책의 영향을 받지 않습니다.
- **오프라인 동작**: 인터넷 연결이 필요 없고, 데이터가 외부로 전송되지 않습니다.
- **영구 저장**: 브라우저 내장 DB(IndexedDB)에 데이터를 저장하므로 HTML을 닫았다 열어도 쪽지가 유지됩니다.
- **자동 중복 제거**: 여러 백업 파일에 같은 쪽지가 포함되어 있어도 한 번만 표시됩니다.
- **인용 복원**: 답장 쪽지에 포함된 이전 대화 인용부에서 원본 쪽지도 자동 복원합니다.
- **카카오톡 스타일 UI**: 대화 상대별로 그룹화되어 시간순 말풍선으로 표시됩니다.
- **실시간 검색**: 이름·제목·내용을 검색하고 매칭 부분을 하이라이트합니다. 검색 결과가 여러 건일 때 이전/다음 버튼으로 해당 쪽지 사이를 이동할 수 있습니다.
- **쪽지 별표**: 자주 보고싶은 쪽지를 별표해두고 "⭐ 저장한 쪽지" 탭에서 모아볼 수 있습니다.
- **쪽지 숨기기**: 보고 싶지 않은 쪽지를 숨겨 채팅창·검색에서 제외하고, "🙈 숨김" 탭에서 따로 관리하거나 영구 삭제할 수 있습니다.
- **검색어 저장**: 자주 쓰는 검색어를 등록해두고 한 번의 클릭으로 즉시 검색할 수 있습니다.
- **백업 주기 알림**: 마지막 업로드 경과일을 표시하고, 20일이 지나면 백업 갱신 경고 배너를 띄웁니다.
- **다양한 입력 방식**: txt 파일 드래그앤드롭·선택은 물론, 파일 업로드가 막힌 환경에서는 텍스트를 복사·붙여넣어 쪽지를 추가할 수 있습니다.
- **CSV 내보내기**: 검색 결과를 엑셀에서 열 수 있는 CSV로 내보낼 수 있습니다.

## 사용법

1. `releases/v1.4/TTalk_쪽지뷰어.html` (최신 버전) 파일을 다운로드하여 PC의 원하는 위치에 저장합니다.
2. 파일을 더블클릭하면 기본 브라우저에서 열립니다.
3. 상단의 "📥 쪽지 추가" 버튼을 클릭한 뒤, 다음 두 방식 중 하나로 쪽지를 추가합니다.
   - **파일로 추가**: TTalk에서 내려받은 받은쪽지함/보낸쪽지함 txt 파일을 드래그앤드롭하거나 선택합니다.
   - **텍스트 붙여넣기**: txt 파일을 메모장 등으로 열어 전체 복사한 뒤, 받은/보낸 구분을 선택하고 붙여넣습니다.
4. 왼쪽 사이드바에서 대화 상대를 선택하면 오른쪽에 쪽지 내역이 채팅 형태로 표시됩니다.

### 텍스트 붙여넣기 (파일 업로드 차단 환경)

사내 보안 프로그램이 브라우저의 파일 업로드를 차단하는 경우, "📋 텍스트 붙여넣기" 탭을 사용합니다. TTalk에서 받은 txt 파일을 메모장으로 열어 `Ctrl+A` → `Ctrl+C`로 전체 복사한 뒤, 모달의 텍스트 영역에 `Ctrl+V`로 붙여넣고 "쪽지 저장"을 누르면 됩니다. 붙여넣은 내용도 파일과 동일하게 파싱·중복 제거됩니다.

### 암호화된 파일

txt 파일이 암호화되어 있으면 정상적으로 읽을 수 없습니다. 메모장으로 파일을 열었을 때 글자가 깨져 보인다면 암호화된 상태이므로, 복호화 후 다시 업로드(또는 복사·붙여넣기)해주세요. 빈 페이지 홈과 파일 추가 모달에도 동일한 안내가 표시됩니다.

### 별표 사용

쪽지 말풍선에 마우스를 올리면 나타나는 ☆ 버튼을 클릭하면 별표가 지정됩니다. 사이드바 상단의 "⭐ 저장" 탭에서 별표한 쪽지를 모아볼 수 있고, 항목을 클릭하면 원본 대화 위치로 이동합니다.

### 쪽지 숨기기 사용

쪽지 말풍선에 마우스를 올리면 별표 옆에 나타나는 🗂️ 버튼을 클릭하면 해당 쪽지가 숨겨집니다. 채팅창 상단 발신자 이름 옆의 "🗂️ 발신자 전체 숨기기" 버튼을 누르면 그 발신자가 보낸 모든 쪽지를 한 번에 숨길 수 있습니다. 숨긴 쪽지는 채팅창과 검색에서 제외되며, 사이드바 "🗂️ 숨김" 탭에서 모아볼 수 있습니다. 숨김 탭의 각 항목은 "복원" 버튼으로 다시 표시할 수 있고, 탭 상단의 "전체 삭제" 버튼으로 숨긴 쪽지를 영구 삭제할 수 있습니다.

### 검색어 저장 사용

사이드바의 "🔖 저장한 검색어" 영역에서 "+ 추가" 버튼으로 자주 쓰는 검색어를 등록합니다. 저장된 검색어 칩을 클릭하면 즉시 해당 키워드로 검색되며, 칩의 × 버튼으로 삭제할 수 있습니다.

### 검색 결과 이동

검색을 하면 채팅창 하단에 "◀ 이전 / N번째 / 다음 ▶" 바가 나타납니다. 버튼을 누르면 검색어가 포함된 쪽지로 차례대로 이동하며, 해당 쪽지가 노란 테두리로 강조됩니다. 검색창에서 `Enter`(다음) / `Shift+Enter`(이전) 키로도 이동할 수 있습니다.
